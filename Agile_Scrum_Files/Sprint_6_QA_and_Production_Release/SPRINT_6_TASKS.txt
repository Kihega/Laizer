BUG SEVERITY LEVELS
--------------------
P1 - Critical : App crashes, data loss, security breach, login broken.
                Must be fixed before release. Blocks production build.
P2 - Major    : Core feature broken or unusable. Must be fixed before release.
P3 - Minor    : Non-critical issue or cosmetic defect. Can be fixed post-release.
P4 - Trivial  : Very minor. Logged for a future sprint.
