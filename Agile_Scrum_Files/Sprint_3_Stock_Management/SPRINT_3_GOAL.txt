SPRINT GOAL
-----------
"By the end of Sprint 3, a worker can register new stock items with
quantity, unit, and price for their centre, update quantities, and view
their centre's stock list -- while the owner can see all stock levels
across all centres including live updates."


WHAT WILL BE TRUE AT THE END OF THIS SPRINT
---------------------------------------------
  - Worker can add a new stock item (name, quantity in pcs or boxes,
    net price in Tanzanian Shillings)
  - Worker can view all stock items registered at their centre
  - Worker can update the quantity of an existing item
  - Worker can remove an incorrect stock entry
  - Quantity cannot be negative; price must be a valid positive number
  - Currency amounts display formatted as "Tshs X,XXX"
  - Owner can view stock across all centres from the dashboard
  - Stock updates appear in real time on the owner's dashboard
    without requiring a manual refresh


STORIES IN THIS SPRINT
-----------------------

  US-030  Worker registers new stock item         5 points
  US-031  Worker views stock list at centre       3 points
  US-032  Worker updates stock item quantity      3 points
  US-036  Worker deletes incorrect stock entry    2 points
  US-034  Owner views stock across all centres    5 points
  US-035  Owner sees live stock updates           5 points
  STCK-X  Stock list sorting (name and quantity)  3 points

  Total: 26 points


TECHNICAL NOTES FOR THE TEAM
------------------------------
  - Live updates (US-035) use Supabase Realtime. Subscribe to INSERT
    events on the stock_items table filtered by the owner's centre IDs.
    Unsubscribe when the screen unmounts to avoid memory leaks.

  - The unit field must be a dropdown or radio button: "pcs" or "boxes".
    Do not allow free text entry for units.

  - Price formatting: store raw numeric values in the database. Format
    for display only (e.g. 19500 stored, "Tshs 19,500" displayed).

  - Delete is a hard delete (remove the record). Add a confirmation
    dialog before deleting. Soft delete is not required for stock items.
