STORY US-030 : Register New Stock Item (5 pts)
-----------------------------------------------
As a worker, I want to register a new stock item with name, quantity,
unit, and net price so that the centre's inventory is tracked.

Acceptance Criteria:
  1. The form has fields for: Item Name, Quantity, Unit (pcs or boxes),
     Net Stock Price in Tshs.
  2. All fields are required. Quantity must be 0 or greater.
     Price must be greater than 0.
  3. Unit is selected from a picker (pcs or boxes), not typed manually.
  4. On success, the new item appears immediately in the stock list.
  5. The registered_by field is automatically set to the logged-in worker.

Tasks:
  [ ] Build Add Stock Item screen with form and validation
  [ ] Unit picker (pcs / boxes dropdown)
  [ ] Numeric keyboard for quantity and price fields
  [ ] Insert into stock_items table with centre_id and registered_by
  [ ] Navigate back to stock list after save
  [ ] Show new item in list immediately (React Query invalidation)


STORY US-031 : View Stock List at Centre (3 pts)
-------------------------------------------------
As a worker, I want to view all stock items at my centre so that I know
what inventory is available.

Acceptance Criteria:
  1. The stock list shows item name, quantity, unit, and price for each item.
  2. Items are sorted alphabetically by name by default.
  3. An empty state is shown when no items are registered yet.

Tasks:
  [ ] Build Stock List screen showing all items for the worker's centre
  [ ] Fetch stock_items filtered by centre_id (from auth store)
  [ ] Display name, quantity + unit, and formatted price per item
  [ ] Empty state component
  [ ] Default alphabetical sort


STORY US-032 : Update Stock Item Quantity (3 pts)
--------------------------------------------------
As a worker, I want to update the quantity of an existing stock item so
that inventory counts stay accurate after restocking or usage.

Acceptance Criteria:
  1. Tapping a stock item opens an edit form pre-filled with current values.
  2. The worker can change the quantity and price. Item name and unit
     can also be edited.
  3. Quantity cannot be set below 0.
  4. Saving updates the record and returns to the stock list.

Tasks:
  [ ] Build Edit Stock Item form (pre-filled)
  [ ] Validate quantity >= 0 before saving
  [ ] Implement update query on stock_items table
  [ ] Update updated_at timestamp on save
  [ ] Return to stock list after successful update


STORY US-036 : Delete Incorrect Stock Entry (2 pts)
----------------------------------------------------
As a worker, I want to delete an incorrectly entered stock item so that
the inventory list stays accurate.

Acceptance Criteria:
  1. A delete option is available on the stock item detail or edit screen.
  2. A confirmation dialog appears before deletion.
  3. After deletion, the item is immediately removed from the list.

Tasks:
  [ ] Add delete button with confirmation dialog on edit screen
  [ ] Implement delete query on stock_items table
  [ ] Remove item from list immediately after deletion (React Query)


STORY US-034 : Owner Views Stock Across All Centres (5 pts)
------------------------------------------------------------
As an owner, I want to view stock levels across all my centres so that
I can identify where restocking is needed.

Acceptance Criteria:
  1. The owner's dashboard has a Stock section listing items by centre.
  2. The owner can filter the view to show one specific centre at a time.
  3. Each item shows name, quantity, unit, and price.
  4. The list updates when a worker adds or edits a stock item.

Tasks:
  [ ] Build Stock overview section on Owner Dashboard
  [ ] Fetch all stock_items for all owner's centres (RLS-filtered)
  [ ] Centre filter dropdown on the stock overview screen
  [ ] Display items grouped by centre


STORY US-035 : Live Stock Updates for Owner (5 pts)
----------------------------------------------------
As an owner, I want to see live stock updates per centre without
having to refresh the screen manually.

Acceptance Criteria:
  1. When a worker adds a new stock item, it appears on the owner's
     screen within 3 seconds.
  2. When a worker updates a quantity, the change reflects on the
     owner's screen within 3 seconds.

Tasks:
  [ ] Set up Supabase Realtime subscription on stock_items table
      scoped to owner's centre IDs
  [ ] Invalidate React Query cache on realtime INSERT or UPDATE event
  [ ] Unsubscribe from realtime channel on screen unmount
  [ ] Test with two devices: worker adds item, owner sees it appear


STOCK LIST SORTING (3 pts)
---------------------------
As a worker or owner, I want to sort the stock list by name or by
quantity so I can find items quickly.

Acceptance Criteria:
  1. A sort control allows switching between: Name A-Z, Name Z-A,
     Quantity Low to High, Quantity High to Low.
  2. The default sort is Name A-Z.
  3. The selected sort order is remembered during the session.

Tasks:
  [ ] Add sort control to stock list screen
  [ ] Implement client-side sort for the four options
  [ ] Store current sort preference in local component state
