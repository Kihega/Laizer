SPRINT GOAL
-----------
"By the end of Sprint 0, every developer has a running local environment,
the GitHub monorepo workspace is scaffolded with pnpm, the Express.js backend
runs locally and on Render, Prisma is connected to Supabase PostgreSQL with all
tables migrated, Upstash Redis is connected, and the Expo mobile app renders
on a device."


SPRINT 0 DELIVERABLES
-----------------------
  1. pnpm workspaces running from the monorepo root
  2. Express.js backend running locally (pnpm dev in apps/backend)
  3. Expo mobile app running on a device (pnpm dev in apps/mobile)
  4. Prisma connected to Supabase PostgreSQL, all 8 tables migrated
  5. Upstash Redis connected and reachable from the backend
  6. JWT sign, verify, and revoke helpers working
  7. Backend deployed to Render free tier (even if just health check)
  8. GitHub Actions pr-checks.yml passing on a test pull request
  9. GitHub Actions deploy-production.yml configured with EXPO_TOKEN
  10. Project README with step-by-step setup instructions
