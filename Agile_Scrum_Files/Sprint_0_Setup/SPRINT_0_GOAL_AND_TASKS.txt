SPRINT GOAL
-----------
"By the end of Sprint 0, every developer has a running local environment,
the GitHub monorepo is scaffolded with main and develop branches protected,
GitHub Actions CI/CD workflows are passing, Supabase database tables are
created, and the Expo mobile app renders on a physical or virtual device."


WHY THIS SPRINT EXISTS
-----------------------
Sprint 0 is a setup sprint. It produces no user-facing features.
Its job is to remove all infrastructure risks before development begins
so that Sprint 1 can focus entirely on writing app features. Every hour
spent here saves many hours of debugging broken environments later.


SPRINT 0 DELIVERABLES
-----------------------
  1. GitHub repository live with main and develop branches protected
  2. Monorepo scaffolded with Turborepo and pnpm workspaces
  3. Expo app running on device (even just a blank screen)
  4. Supabase project created with all 8 database tables migrated
  5. Row-Level Security enabled on all tables
  6. GitHub Actions: pr-checks.yml passing on a test pull request
  7. GitHub Actions: deploy-production.yml configured with EXPO_TOKEN
  8. Project README with setup instructions that a new developer can follow
