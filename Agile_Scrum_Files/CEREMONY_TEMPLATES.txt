TEMPLATE 5 : PULL REQUEST DESCRIPTION
================================================================================

Use this template when opening a Pull Request on GitHub.
Copy this text into the PR description box.


PULL REQUEST DESCRIPTION
-------------------------

Story / Issue Reference: Closes #[Story ID or Issue Number]

What does this PR do?
  ____________________________________________________________
  ____________________________________________________________

Type of change (tick all that apply):
  [ ] feat     -- New feature
  [ ] fix      -- Bug fix
  [ ] chore    -- Configuration or tooling change
  [ ] docs     -- Documentation only
  [ ] refactor -- Code restructure, no behaviour change
  [ ] test     -- Tests only


TESTING DONE
------------
  [ ] Tested on Android device or emulator
  [ ] Happy path works correctly
  [ ] Error states handled (invalid input, network failure)
  [ ] No regressions found in existing features


DEFINITION OF DONE CHECKLIST
------------------------------
  [ ] All acceptance criteria met
  [ ] No TypeScript errors
  [ ] ESLint passes
  [ ] Unit tests written where applicable
  [ ] RLS policies tested if database changes were made
  [ ] PR title follows Conventional Commits format


SCREENSHOTS OR SCREEN RECORDING
---------------------------------
  Attach screenshots or a short screen recording if the PR includes
  any visible UI changes.
